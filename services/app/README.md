# Административная консоль

## Описание
Предназначена для управления системой и предоставляет функции:
- Управление абонентами
- Формирование голосового приветствия
- Управление конфигурацией (БД, модули)
- Формирование отчётов

### Управление пользователями
Функции:
- просмотр списка пользователей
- добавление, изменение и удаление абонента
данные хранятся в таблице users 


### Управление абонентами astersik
Функции:
- просмотр списка абонентов
- добавление, изменение и удаление абонента
- выгрузка абонентов в csv файл
- загрузка абонентов из csv файла

Данные храняться таблицах:
- ps_endpoints
- ps_aors
- ps_auth

Для хранения пароля абонента применяется MD5

### Формирование голосового приветствия
- прослушивание существующего файла
- загрузка нового файла
- удаление файла
- запись файла приветсвия

### Управление конфигурацией
- настройка параметров БД
- настройка списка категорий
- выбор модулей системы из списка (распознование голоса, детектор категории, детектор проблем диалога)

### Формирование отчётов
- статистика звонков по абонентам
- статистика проблемных звонков
